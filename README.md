## 前提条件

- **Minecraft**: Java Edition
- **Modローダー**: Fabric
- **前提Mod**: Fabric API
- **推奨Mod**: ModMenu

## ビルド方法

### MOD をビルド
```
./gradlew build
```

### 開発用クライアントを起動
```
./gradlew runClient
```

### 開発用サーバーを起動
```
./gradlew runServer
```

## Node.js ブリッジのセットアップ

```bash
cd node-bridge
npm install
```
