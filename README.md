## 前提条件

- **Minecraft**: JE 1.21.10
- **Modローダー**: Fabric

## ビルド方法

### MOD をビルド
```
./gradlew build
```

### 開発用クライアントを起動
```
./gradlew runClient
```

### 開発用サーバーを起動
```
./gradlew runServer
```

## Node.js ブリッジのセットアップ

```bash
cd node-bridge
npm install
```
