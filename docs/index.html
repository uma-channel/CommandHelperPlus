コマンドを、もっと自由に。

Command Helper Plus は、Minecraft のコマンド作業を快適にします。痒い所に手が届く、必須級の便利 MOD です。

ダウンロード特長を見る

    コマンド作業を、まるごと快適に。

    コマンドを使うときの面倒を、ひとつずつ軽くします。項目を選ぶと、機能の一覧が開きます。

    導入は、3ステップ。

    特別な準備は要りません。

    1

    ダウンロード

    Modrinth から MOD ファイルを入手します。

    2

    入れる

    Fabric と Fabric API を入れた mods フォルダに置きます。

    3

    遊ぶ

    ゲームを起動します。

    ゲーム画面を、のぞいてみる。

    クリックで拡大します。

    さあ、コマンドをもっと快適に。

    Command Helper Plus で、コマンド作業をスピードアップ。
