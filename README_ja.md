### Command Helper Plus は、Minecraft のコマンド作業を快適にします。
### 痒い所に手が届く、必須級の便利 MOD です。

# 概要

- **[公式サイト](https://chp.clpc.club)をご確認ください。**
- **[Modrinth](https://modrinth.com/mod/cmd-helper-plus)からModをダウンロードできます。**

# 前提条件

- **Minecraft**: Java Edition
- **Modローダー**: Fabric
- **前提Mod**: [Fabric API](https://modrinth.com/mod/fabric-api/versions?c=release)
- **推奨Mod**: [ModMenu](https://modrinth.com/mod/modmenu/versions?c=release&l=fabric)
- **動作環境**: クライアントサイドのみ、サーバーサイドのみ、またはその両方 

# ビルド方法

### MOD をビルド
```
./gradlew build
```

### 開発用クライアントを起動
```
./gradlew runClient
```

### 開発用サーバーを起動
```
./gradlew runServer
```

# Node.js ブリッジのセットアップ

```bash
cd node-bridge
npm install
```
