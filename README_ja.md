### Command Helper Plus は、Minecraft のコマンド作業を快適にします。
### 痒い所に手が届く、必須級の便利 MOD です。

# 概要

- **[公式サイト](https://chp.clpc.club)をご確認ください。**
- **[Modrinth](https://modrinth.com/mod/cmd-helper-plus)からModをダウンロードできます。**

# 機能一覧

下の各項目をクリックすると、詳細な機能の一覧が展開されます。

<details>
<summary><b>1. 補完 (Completion)</b> — 入力を快適にし、迷いをなくす機能</summary>

* **SpyglassMC の補完**: チャット欄とコマンドブロック（ブロック・トロッコ）の編集画面で、SpyglassMC の候補をバニラの補完に統合します。
* **構造記号の候補**: `[ { " ] } , = :` を候補に出し、キーの候補には区切りも付けます。
* **自動閉じ**: 括弧と引用符を自動で閉じます。閉じ記号の上書き、Backspace でのペア削除、Tab やクリックで確定した後にも対応します。
* **候補の型を表示**: 候補の右側に `[boolean]` や `[float]` のように型を薄く表示します。
* **{Command:"…"} の中**: 文字列の中身を1つのコマンドとして補完します。内側の自動閉じ・自動エスケープにも対応します。
* **権限に応じた候補**: コマンド名の位置では、自分の権限で使えるコマンドだけに絞ります。
* **バージョンに追従**: 遊んでいる Minecraft のバージョンに合わせた候補を出します。任意のバージョンも設定で指定できます。

</details>

<details>
<summary><b>2. 構文チェック (Syntax check)</b> — 実行前に誤りを見つける機能</summary>

* **下線で誤りを表示**: 入力が止まって少しすると、誤りの部分に下線を付けます。エラーは赤、警告は黄色です。
* **理由をツールチップで**: 下線にマウスを重ねると、エラーの文言が出ます。横にスクロールしている長いコマンドでも使えます。
* **コマンドブロックでも**: チャット欄とコマンドブロックの編集画面の、どちらでも動きます。
* **{Command:"…"} の内側も**: 入れ子の文字列の内側の誤りにも、下線が付きます。
* **存在する ID の確認**: データパックのファンクションなどの ID や、プラグイン/MOD等によるカスタムコマンドは警告がでません。存在しない ID は黄色になります。

</details>

<details>
<summary><b>3. 履歴・お気に入り (History & favorites)</b> — コマンドの管理と再利用を便利にする機能</summary>

* **履歴ボタン**: チャット欄の入力欄の上に「履歴」ボタンを追加。履歴とお気に入りの2タブの画面が開きます。
* **検索**: 語句で履歴とお気に入りを絞り込みます。空白区切りで AND、大文字小文字は区別しません。
* **クリックで入力欄へ**: 行をクリックするとチャット欄に戻り、入力欄に反映されます。右クリックでコピーします。
* **保存件数の引き上げ**: バニラは50件までですが、既定で1000件まで保存します。設定で50〜100000件に変えられます。
* **重複の自動統合**: 同じコマンドは1件にまとめ、最後に使った順に並べます。↑↓の履歴にもすぐ反映されます。
* **お気に入り**: ☆で登録・解除。通常履歴の上限や重複統合の対象外で、独立して保存されます。
* **ショートカットキー**: お気に入りに、Ctrl・Alt・Super を含むキーを割り当てられます。押すと入力欄がそのコマンドに置き換わります（実行はしません）。
* **削除は必ず確認**: 削除の前に確認画面を挟みます。履歴の削除だけは、設定で確認を省けます。

</details>

<details>
<summary><b>4. コマンドブロック (Command blocks)</b> — ブロックの編集を快適にする機能</summary>

* **横スクロール**: コマンドが入力欄に収まらないとき、下にスクロールバーを表示。ドラッグ・クリック・マウスホイールで動かせます。カーソルは動きません。
* **トロッコにも対応**: コマンドブロックとトロッコ付きコマンドブロックの、両方の編集画面で使えます。
* **照準で内容を表示** `[op 必要]`: コマンドブロックに照準を合わせると、中身を右下に表示します。長いコマンドは8行で省略します。設定でオン・オフできます。

</details>

<details>
<summary><b>5. 長いコマンド (Long commands)</b> — 制限を超える長文入力を可能にする機能</summary>

* **制限を引き上げ**: 「/」で始まるコマンドだけ、既定で32767文字まで入力・送信できます。設定で256〜32767文字に変えられます。
* **横スクロール**: 上下マウスホイールで左右に動かせます。カーソルは動きません。
* **通常の発言はそのまま**: 「/」のない発言は、バニラどおり256文字です。
* **署名付きコマンドの安全策**: `/say` や `/msg` のように署名付きの引数を持つコマンドは、接続が切れないよう256文字に切り詰めて送ります。
* **戻しても切れない**: 履歴画面から戻したときや、ウィンドウサイズを変えたときも、長い入力が切り詰められません。

</details>

<details>
<summary><b>6. ゲーム操作 (Game controls)</b> — プレイ中の面倒な手順を短縮する機能</summary>

* **再参加**: ポーズ画面にボタンを追加。シングルは同じワールドへ、マルチは同じサーバーへ入り直します。Realms は対象外です。
* **再起動**: タイトル画面にボタンを追加。同じ起動構成でゲームを起動し直します。確認画面では、起動コマンドを初期状態で伏せます。
* **データパックを速く読み直す**: `/reload` の処理を最適化します。サーバーサイドに導入すればマルチプレイでも機能します。
* **データパックフォルダを開く**: ポーズ画面のボタンから、ワールドの datapacks フォルダを開きます（シングルプレイ）。
* **設定ファイルを開く**: 設定画面から、設定ファイルと設定フォルダをすぐ開けます。
* **実験的設定の確認を省く**: ワールドを開く・作るときの、実験的な設定の確認を自動で飛ばします。既定はオフです。

</details>

<details>
<summary><b>7. 表示 (Display)</b> — ワールド内の情報を可視化する機能</summary>

* **スコアボード HUD** `[op 必要]`: 複数のスコアボードを画面左上に同時に表示します。対象のセレクターを設定でき、架空のプレイヤーも指定できます（最大4つ）。
* **透明なエンティティを半透明に**: 透明化したエンティティが半透明に見えます。スペクテイターでなくても使え、op は不要です。
* **marker の表示** `[op 必要]`: クライアントには届かない marker を、パーティクルの十字で表示します。
* **ネームタグの強制表示**: チームの設定や透明化で隠れているネームタグを表示します。透明化は、半透明化がオンのときだけ対象です。

</details>

<details>
<summary><b>8. 設定 (Settings)</b> — 機能を柔軟にカスタマイズする設定画面</summary>

* **設定画面**: Mod Menu から開けます。操作設定の「設定を開く」で割り当てたキー（既定は O）からも開けます。
* **項目が多い**: 補完、自動閉じ、構文チェック、文字数制限、履歴の保存件数、HUD など、機能ごとに切り替えられます。
* **再起動なしで反映**: 画面で変えた設定は、そのままゲームに反映されます。

</details>
